# 🛒 Sistema de Gestión de Minimarket

Proyecto desarrollado de manera **colaborativa** como parte del Certificador de Desarrollo de Software 2.

El sistema permite gestionar productos, proveedores, categorías, inventario y ventas mediante una aplicación web desarrollada con **C#, ASP.NET MVC, Entity Framework y SQL Server**.

---

## 🤝 Trabajo colaborativo

El proyecto fue desarrollado por un equipo de **2 integrantes**, utilizando Git y GitHub para organizar y mantener los cambios realizados durante el desarrollo.

Durante el proyecto se trabajó en:

* División de funcionalidades entre los integrantes.
* Integración de cambios mediante Git.
* Seguimiento de avances mediante commits.
* Revisión y validación conjunta de funcionalidades.
* Integración de módulos dentro de una misma solución.
* Resolución de errores durante la integración del proyecto.

El trabajo permitió aplicar no solo conocimientos técnicos, sino también coordinación, comunicación y organización durante el desarrollo de software.

## 🎯 Objetivo

Desarrollar un sistema web que permita centralizar y facilitar la gestión de las principales operaciones de un minimarket.

El sistema busca mantener organizada la información relacionada con productos, proveedores, categorías, stock y ventas.

---

## ✨ Funcionalidades principales

* Registro y gestión de productos.
* Gestión de proveedores.
* Administración de categorías.
* Control de inventario y stock.
* Registro y gestión de ventas.
* Consulta y actualización de información.
* Persistencia de datos mediante SQL Server.
* Interfaz web adaptable mediante Bootstrap.

---

## 🧩 Arquitectura MVC

El proyecto utiliza el patrón **Modelo - Vista - Controlador (MVC)** para separar las responsabilidades de la aplicación.

### Modelo

Representa las entidades del sistema y permite interactuar con la base de datos mediante Entity Framework.

### Vista

Presenta la información al usuario mediante interfaces desarrolladas con HTML, CSS y Bootstrap.

### Controlador

Procesa las solicitudes realizadas por el usuario y coordina la comunicación entre los modelos y las vistas.

---

## 🗄️ Base de datos

La información del sistema se almacena en **SQL Server**, utilizando Entity Framework para trabajar con las entidades y realizar operaciones sobre los datos.

Entre las principales entidades del sistema se encuentran:

* Productos
* Proveedores
* Categorías
* Inventario
* Ventas
